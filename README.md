# Mi Proyecto Integrador

## Descripción
Este proyecto consiste en una página web básica para la gestión y presentación de contenidos digitales.

## Objetivo
Aplicar los conocimientos adquiridos en el curso sobre versionado con Git y colaboración en GitHub.

## Estructura del repositorio
- `README.md`: Documentación principal del proyecto.
- `ENTREGA.md`: Registro del proceso de trabajo y datos de entrega.
- `proyecto/`: Carpeta que contiene el código fuente de la página web (`index.html` y `styles.css`).
